# 智能软件工程学习平台 Demo · 测试计划

版本：V1.0 ｜ 日期：2026-11-16 ｜ 编制：第四组（杨逸）｜ 适用对象：smart-learning-demo（V2）

## 1 引言

### 1.1 目的

验证学习平台 Demo 的学、记、诊三个核心模块与 AI 评测功能是否按立项定义正确工作，重点验证：

1. 作答记录（答案、理由、耗时、判分类型）完整且不可篡改；
2. 薄弱项判定"准确率第一依据、正确作答时间第二依据"可复现、阈值可配置；
3. 难题（题目级）、难点（班级聚合）、重点（真题分值）三类产出符合定义；
4. AI 评测四指标可运行、结果入台账、可复查；
5. 学习资料上传与三端展示可用。

## 3 测试策略与方法

### 3.1 功能测试

- 按业务场景覆盖：学生完整学习闭环（学→练→诊断→画像）、教师复核闭环、管理员配置闭环
- 每个场景至少覆盖：正常流、异常流（缺参、非法值、无权限对象不存在）、边界流

### 3.2 判定规则测试（本项目的重点）

采用与课程一致的用例设计方法：

| 方法 | 应用点 |
|---|---|
| 等价类划分 | 准确率：<60%（薄弱）/ ≥60%（达标）；判分类型：客观题/主观题 |
| 边界值分析 | 准确率 59%/60%/61%；时间比值 1.49/1.50/1.51；样本数 N-1/N/N+1；分值占比 19.9%/20%/20.1% |
| 判定表 | 准确率 × 时间证据 × 样本数 的组合判定（覆盖 6 种组合） |
| 场景法 | 复核改判后重新诊断；证据从无到有状态迁移 |
| 错误推测 | 空作答、重复提交、非法 question_id、删除后访问 |

### 3.3 接口测试

- 用 curl 脚本逐接口验证状态码、字段、错误信息
- 重点验证：提交接口的 duration_sec 落库、复核接口的留痕与重算、评测接口的台账写入

### 3.4 AI 评测验证

- 使用固定标注集（DS-KP-EXTRACT 3 条、DS-RELATION 5 条），同一输入重复运行两次验证结果可复现
- 校验指标计算口径：召回（包含匹配）、准确率（命中/抽取总数）、出处可定位（原文包含）
- 校验台账字段：run_type、engine、model_version、prompt_version、metrics、passed、时间
- 校验回退：无凭据/调用失败时 engine 必须标为 RULE_FALLBACK，不得伪装为 LLM 结果

### 3.5 数据一致性与迁移

- 增量迁移（migrate_db）重复执行两次，确认幂等
- 全新数据库执行 init → migrate → seed，确认无字段错位
- 删除资源后确认磁盘文件同步删除

### 3.6 非功能测试（抽样）

| 类型 | 检查项 |
|---|---|
| 性能 | 重难点看板接口响应 < 1s（当前数据量）；大文件上传 50MB 可完成 |
| 安全 | 路径穿越（/uploads/../）、扩展名伪装、超限上传、SQL 注入抽样 |
| 兼容 | Chrome / Edge / Safari 各端页面可用（手工抽查） |
| 可用性 | 无凭据时 AI 功能降级不影响主流程 |

### 3.7 回归策略

- 每轮修复后执行：核心闭环冒烟（学习→答题→诊断→复核→评测）+ 本计划 3.2 全部判定规则用例
- 失败样例进入回归集，对应 REQ-QA-03

## 7 准入与准出标准

### 7.1 准入

- 代码可启动，三端页面可访问
- 数据库可重建，种子数据完整
- 核心接口联调通过（学/记/诊/AI评测）

### 7.2 缺陷等级

| 等级 | 定义 | 示例 |
|---|---|---|
| P0 致命 | 主流程不可用、数据损坏 | 服务无法启动、答题不落库 |
| P1 严重 | 核心判定错误、结果不可信 | 薄弱项判定与规则不符、评测台账缺失 |
| P2 一般 | 功能可用但结果/提示有偏差 | 提示文案错误、列表字段缺失 |
| P3 轻微 | 体验问题 | 样式错位、文案不通顺 |

### 7.3 准出

- P0、P1 缺陷全部关闭；P2 关闭率 ≥ 90%
- 判定规则用例（TC-DIA、TC-DIF）通过率 100%
- AI 评测可运行且台账完整（指标是否达标不构成准出条件，但必须如实记录）
- 核心闭环冒烟 100% 通过

## 9 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| LLM 输出波动导致评测结果不稳定 | 指标不可比 | 固定提示词版本与标注集，记录引擎/版本，重复运行取记录 |
| 无 API 凭据时只能规则回退 | AI 指标失真 | 报告中标注引擎类型，规则结果不用于能力结论 |
| 模拟数据被误当真实学情 | 结论失真 | 所有模拟数据在报告中标"模拟"，阈值标"候选" |
| 测试数据污染演示库 | 演示异常 | 测试前备份 demo.db，测试后恢复 |
| 时间判据依赖样本量 | 小样本误判 | 严格执行 N 门槛用例（TC-DIA-05、TC-DIF-02） |
