# 学习平台前端（三端演示）

对应文档：`../docs/design/系统设计文档.md`、`../docs/design/前后端接口设计.md`
实现范围：学 / 记 / 诊 + 学生自主标识（本组主线）；E5 图谱、E4 标记、画/荐/干按 PPT 契约展示。

## 运行

```bash
cd frontend
python3 -m http.server 5200
# 打开 http://127.0.0.1:5200/
```

也可以直接双击 `index.html`（localStorage 在 file:// 下可用，但建议用本地服务器）。

演示账号（无密码，演示模式）：

| 端 | 账号 |
|---|---|
| 学生 | s1（薄弱·准确率）、s2（薄弱·时间）、s3（已掌握） |
| 教师 | t1、t2 |
| 管理员 | a1 |

地址快捷方式：`student.html?auto=1`、`teacher.html?auto=1`、`admin.html?auto=1` 自动登录第一个账号。

## 功能

**学生端**
- 课程学习：课程结构 / 课件 / 视频 / 单元测验（逐题计时、学完即练提示）
- 诊断结果：准确率第一依据 + 正确作答时间第二依据、证据包、**自主标识薄弱**（与系统判定对比）
- 个人画像（画）：DifficultyMark 列表/筛选、五字段详情、证据深链、证据缺失灰条
- 学习推荐（荐）：推荐请求、候选展示、800ms 降级为 next_check
- 学习记录（干）：回原题 / 去练习 / 问老师，动作日志
- AI 助教、知识图谱、行为记录

**教师端**
- 学情看板；重难点诊断（难题/难点/重点 + 学生自评汇总）
- 主观题复核（AI 初判 → 改判留痕）
- 难点标记审核（E4）：五字段 + 证据链，确认/驳回、调整权重
- 课程管理、课件与资料上传、图谱构建（E5）、文本标注、真题扫描、AI 评测台账

**管理端**
- 系统概览、用户/课程/资源/题目管理、阈值配置、日志、AI 模型、CI/CD、备份、安全

## 数据与接口

- 数据保存在浏览器 `localStorage`（key：`smart-learning-db-v2`），可在门户页“重置演示数据”。
- `js/api.js` 是 Mock API，按《前后端接口设计.md》的路径与响应封装；接入后端时把 `api()` 换成真实 `fetch` 即可，页面代码不变。
- 学记诊部分按本组设计实现；画/荐/干按第四组汇报 PPT 的只读/只写契约展示（DifficultyMark、RecommendRequest、InterventionLog）。
- 演示数据（答题耗时、真题分值、标记）为构造数据，阈值均为候选值。

## 已知限制

- 演示模式无密码、无 JWT；正式部署需接后端鉴权。
- 上传仅保存元数据，图片小于 300KB 时保存为 dataURL；视频不落盘。
- E4 标记与推荐结果在 Mock 层按固定规则生成，不代表真实模型效果。
